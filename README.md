# Sendrift

**Share files. Leave no clutter.**

Sendrift — минималистичный сервис временного обмена файлами. Отправитель загружает **один файл**, задаёт срок хранения и получает приватную ссылку. Получателю не нужна регистрация. После истечения срока доступ прекращается сразу, а физическое удаление из хранилища выполняет фоновый процесс.

> **Статус репозитория:** техническая спецификация до начала реализации. Наличие этих документов **не означает**, что приложение уже работает.

## Основная идея

- Быстро: выбрать файл → загрузить → скопировать ссылку.
- Предсказуемо: один файл, понятный срок жизни ссылки, никаких обязательных аккаунтов.
- Приватно по ссылке: файл недоступен без криптографически случайного токена; это **не** сквозное шифрование.
- Без лишних функций: только то, что можно качественно реализовать и проверить.

## MVP

1. Анонимная загрузка одного файла размером от 1 байта до **100 MiB**.
2. Drag & drop, выбор файла с устройства и достоверный прогресс загрузки.
3. Срок хранения на выбор: **1 час / 24 часа / 7 дней**.
4. Генерация ссылки вида `/s/<share_token>` и отдельного секретного токена управления.
5. Страница получателя с именем, размером, сроком доступности и кнопкой скачивания.
6. Скачивание только через API после проверки токена и срока действия.
7. Ручное удаление по секретному токену управления.
8. Автоматическая очистка просроченных файлов с повторными попытками при ошибках.
9. Ограничение размера, базовое противодействие злоупотреблениям, логи без секретов и тесты.

**Отложено:** аккаунты, списки файлов, zip-архивы, многофайловые ссылки, пароли, одноразовые ссылки, лимиты скачиваний, QR-коды, chunked/resumable upload, прямые S3 presigned uploads, почтовая отправка, платные тарифы, AI.

## Стек

| Зона | Технологии | Роль |
| --- | --- | --- |
| Web | Next.js, TypeScript, Tailwind CSS | Интерфейс и маршруты `/`, `/s/[token]` |
| API | Python, FastAPI, Pydantic | Валидация, бизнес-правила, выдача доступа |
| Data | PostgreSQL, SQLAlchemy, Alembic | Метаданные, состояния, сроки |
| Objects | MinIO локально; S3-совместимое хранилище в проде | Байты файлов в приватном bucket |
| Worker | Отдельная команда из того же Python-пакета | Очистка и восстановление незавершённых операций |
| Deployment | Docker Compose, reverse proxy | Локальная сборка и небольшой сервер |
| Quality | pytest, ruff, frontend lint/typecheck | Проверки и регрессии |

Redis, Celery, Kafka, Kubernetes и отдельные микросервисы **не нужны для MVP**.

## Как работает

```text
Sender browser
  │ POST /api/v1/shares (multipart/form-data)
  ▼
FastAPI ───────────► PostgreSQL (метаданные, токены в виде хешей)
  │
  └───────────────► Private S3/MinIO bucket (содержимое)
  │
  ▼
Share URL: /s/<token>
  │
Recipient browser ─► Next.js page ─► FastAPI authorization
                                      │
                                      ▼
                                streamed download

Cleanup worker ─────► PostgreSQL + S3/MinIO (удаление)
```

## Порядок разработки

1. Каркас приложений, конфигурация, Docker Compose, PostgreSQL и MinIO.
2. Схема БД, миграция, тесты правил срока хранения.
3. API загрузки и работа с приватным объектным хранилищем.
4. API метаданных, скачивания и ручного удаления.
5. Главная страница, загрузка и прогресс, страница получателя.
6. Worker очистки и сценарии с ошибками/повторными запусками.
7. Интеграционные/E2E тесты и проверка угроз перед публичным запуском.

## Перед публичным запуском

Анонимная загрузка файлов легко становится бесплатным хостингом вредоносного содержимого. Локальный MVP **не равен публично безопасному сервису**. Нужны работающие ограничения загрузок и трафика на периметре, защита от автоматизированных злоупотреблений, мониторинг, процедура жалоб/удаления и проверка безопасности файлов (или обоснованная стратегия обработки риска). Подробности — в `AGENTS.md` и `ARCHITECTURE.md`.
