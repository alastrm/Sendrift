# Frontend assets

- `fonts/InterVariable.woff2`: unmodified Inter variable font by Rasmus Andersson.
  Source: https://github.com/rsms/inter/tree/master/docs/font-files
  License: SIL Open Font License 1.1, included as `fonts/Inter-LICENSE.txt`.
- Sendrift's brand mark and favicon are original SVG artwork.

The font is served locally. The homepage atmosphere uses CSS gradients; no font
CDN requests are made. File transfers use the configured API proxy.
